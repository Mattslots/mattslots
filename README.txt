MATTSLOTS BOT V4 STABLE

Corrige : vérification, rôles, tickets, rôle Membre automatique, délais de réponse Discord, présence du bot et gestion d'erreurs.

INSTALLATION
1. Copie ton fichier .env dans ce dossier.
2. Ouvre CMD dans ce dossier.
3. Lance : npm install puis npm start
4. Dans Discord : /verification puis /roles puis /permissions puis /tickets

IMPORTANT
Le rôle du bot doit être au-dessus des rôles Vérifié, Membre, notifications et Support.
